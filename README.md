# Проект «Вязание» 🧶

**🌐 Сайт — борд идей:** https://ingvar1917.github.io/knitting/
**📌 Pinterest мастера (авторский аккаунт):** https://www.pinterest.com/katsiarynakarol/

Проект для мамы: найти своё направление в вязании (спицы и крючок), реализоваться в любимом деле — творчески и, возможно, финансово.

## Цели

1. Выбрать 1–2 направления, которые нравятся и востребованы.
2. Связать первые «портфельные» работы.
3. Определиться с форматом: продажа изделий, работа на заказ, обучение, контент.
4. Выйти на первую площадку (Ярмарка Мастеров / Авито / соцсети / локальные ярмарки).

## Еженедельный дайджест

Каждый понедельник в 09:00 скрипт собирает свежие новости вязания и отправляет письмом.

- [digest.sh](digest.sh) — главный скрипт: `claude -p` ищет новости по заданию из [prompt-digest.md](prompt-digest.md) и пишет письмо, затем [send_mail.py](send_mail.py) отправляет его через Gmail SMTP
- Секреты (логин, app-пароль, получатели) — в `.env` (не в репозитории; шаблон — [.env.example](.env.example))
- Расписание — systemd-таймер `knitting-digest.timer` (`Persistent=true`: если компьютер был выключен в понедельник, запустится при включении)
- Запуск вручную: `./digest.sh`; тексты писем сохраняются в `out/`
