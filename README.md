# Проект «Вязание» 🧶

**🌐 Сайт — борд идей:** https://ingvar1917.github.io/knitting/
**📌 Pinterest мастера (авторский аккаунт):** https://www.pinterest.com/katsiarynakarol/

Проект для мамы: найти своё направление в вязании (спицы и крючок), реализоваться в любимом деле — творчески и, возможно, финансово.

## Цели

1. Выбрать 1–2 направления, которые нравятся и востребованы.
2. Связать первые «портфельные» работы.
3. Определиться с форматом: продажа изделий, работа на заказ, обучение, контент.
4. Выйти на первую площадку (Ярмарка Мастеров / Авито / соцсети / локальные ярмарки).

## Ежедневное обновление

Каждый день в 09:00: поиск свежих новостей → обновление блока «Свежее» на сайте → публикация → письмо мастеру.

- [update_site.sh](update_site.sh) — главный скрипт. `claude -p` по заданию из [prompt-site.md](prompt-site.md) ищет новое, правит секцию `id="fresh"` в [index.html](index.html) и пишет текст письма; затем скрипт коммитит и пушит страницу, а [send_mail.py](send_mail.py) отправляет письмо через Gmail SMTP
- Секреты (логин, app-пароль, получатели) — в `.env` (не в репозитории; шаблон — [.env.example](.env.example))
- Расписание — systemd-таймер `knitting-site.timer` (`Persistent=true`: если компьютер был выключен, запустится при включении)
- Запуск вручную: `./update_site.sh`; тексты писем и логи — в `out/`

Еженедельный дайджест ([digest.sh](digest.sh) + [prompt-digest.md](prompt-digest.md)) остался в репозитории, но его таймер выключен — ежедневное обновление его заменяет.
